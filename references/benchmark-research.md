# 对标账号视频研究

## 任务信息

先确定博主名称、主页链接、目标视频范围和保存目录。默认研究按发布时间从新到旧排列的最新10条公开视频，仅用于个人内容研究和表达方式分析。

## 获取与转写

1. 仅使用允许访问的公开内容，不绕过登录、付费、反爬或版权限制。
2. 综合读取画面、语音和视频内字幕，以实际语音为主、字幕为校对参考。
3. 需要画面采样时默认每2秒采样一次；工具或素材不支持时说明限制。
4. 不改写观点，不为通顺补写未说过的话。可删除无意义停顿词，但保留有表达作用的语气、重复和停顿。
5. 使用 `[听不清 00:01:25]`、`[人名待确认]`、`[品牌名待确认]` 标注不确定内容。
6. 多人说话时使用“博主”“人物A”“人物B”；重要无声文字使用 `[画面文字：……]`。
7. 商业内容标记为 `[商业合作]` 或 `[疑似商业合作，待确认]`。不复制评论区内容。

## 单条视频文件

每条视频生成一个Markdown文件，包含：

- 标题及基本信息：博主、发布时间、时长、链接、内容类型、商业合作、转写日期、准确度。
- 100字以内内容摘要。
- 按15—30秒分段的时间轴逐字稿；短视频可按自然段划分但保留起始时间。
- 内容结构：开头钩子、痛点或冲突、核心观点、案例或论据、解决方案、结尾方式、互动引导。
- 表达技巧：标题结构、开头方法、叙事节奏、情绪变化、金句位置、转场方式、互动设计。只分析结构，不照搬原句。
- 待人工确认清单。

文件名使用 `序号_发布日期_视频标题简称_逐字稿.md`，移除不适合文件名的符号。

## 总索引与总结

创建 `博主名称_最新10条视频索引.xlsx`，包含序号、博主、标题、发布时间、时长、链接、选题类型、目标人群、开头钩子、内容结构、核心观点、结尾方式、商业合作、准确度、待确认数量和逐字稿路径。

创建 `博主名称_10条视频结构总结.md`，总结重复选题、前三种钩子、常用结构、高频痛点、结尾互动、节奏与平均时长、商业植入、可学习技巧、不宜直接模仿之处和5个差异化选题。

## 受限时处理

如平台规则、版权或权限不允许完整转写，停止逐字转写，改为每条视频的原创摘要和结构分析，并明确说明原因。最终只汇报成功数量、未完成项及原因、保存目录、索引路径和待核对问题。
